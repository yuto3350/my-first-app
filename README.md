# 筋トレ記録アプリ

HTML・CSS・JavaScript だけで動く、個人用の筋トレ記録アプリです。APIキー、外部サービス、パッケージのインストールは不要です。

## 起動方法

1. このフォルダでターミナルを開きます。
2. Python 3 がある環境で `python3 -m http.server 8000 --bind 127.0.0.1` を実行します。
3. 自分のパソコンのブラウザで `http://localhost:8000` を開きます。
4. 終了するときはターミナルで `Ctrl+C` を押します。

上記はパソコンでのローカル実行用です。クラウド環境では提供されている接続方法に従ってください。HTMLファイルを直接開く方法は、ブラウザによって保存の動作が異なるため推奨しません。

## 使い方

- 「胸・背中・脚・その他」から部位を選び、続いて詳しい種目を選択します。重量（kg）、回数、セット数、日付を入力して「記録を保存」を押します。
- 重量は 0〜10000 kg（小数第1位まで）、回数は 1〜10000、セット数は 1〜1000 の整数で入力できます。自重トレーニングは重量を 0 にします。
- 日付の初期値は端末の今日の日付です。過去の日付にも変更できます。
- 一覧の「部位別に見る」で絞り込むと、記録のある日付だけが新しい順に表示されます。日付を押すと、その日の種目・重量・回数・セット数を確認できます。同じ日付では追加の新しい順です。
- 既存の記録も種目から部位を判定して表示します（デッドリフトは背中、肩・腕・腹筋はその他）。
- 「編集」を押すとフォームに内容が戻ります。「変更を保存」で更新し、「編集をキャンセル」で変更を取り消せます。
- 「削除」を押すと確認が表示されます。承認すると削除されます。削除後は元に戻せません。

## 保存について

データはブラウザの `localStorage` に `training-records-v1` というキーで保存します。再読み込み後も残りますが、別の端末やブラウザには同期されません。同じブラウザでも URL のホストやポートが違えば別の保存先になります。ブラウザのデータ削除やプライベートモードの終了で失われる場合があります。バックアップ機能はありません。

保存失敗時はエラーを表示し、入力内容と既存の表示を保持します。保存データが破損している場合や読み取りできない場合は、既存データを上書きしないよう変更を停止します。ブラウザの設定を確認してください。破損データを初期化する場合は、必要に応じて開発者ツールで元データを控えてから、このアプリの保存キーだけを削除してください（記録は失われます）。

## ファイル構成

- `index.html`：入力フォームと一覧の入れ物
- `style.css`：スマートフォンに対応した見た目
- `script.js`：入力チェック、保存、一覧表示、編集、削除
- `README.md`：起動方法と使い方

フレームワークやビルド処理は使っていません。変更後はブラウザを再読み込みして確認できます。
